Bezel

Test page

This page checks whether the Bezel Safari extension is widening pages under Safari's toolbar.

Waiting for Bezel…This takes a moment.
Bezel is workingThis page was widened under Safari's toolbar.
Bezel is off for this pageTurn it on from the Bezel button in Safari's page menu.
Bezel isn't running on this page Fix it in Settings:
  1. Settings → Apps → Safari → Extensions
  2. Tap Bezel, switch it on
  3. Set Allow to All Websites, then reload

Width check

  • Teal: normal page
  • White line: usual edge
  • Purple: widened by Bezel

Purple at the right of the white line means Bezel is working. No purple means the page is its normal width.

This page loads nothing else and collects nothing. It only shows whether the Bezel Safari extension is active.
